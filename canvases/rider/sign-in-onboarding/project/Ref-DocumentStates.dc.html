attachRiderDocument returns a KycDocument. Until the set is sent (submitted_at is null) the app labels it Added; after submitRiderDocuments it is Sent, then In review. Shape, not only words: Added is an outline pill with no glyph; Approved is the only state with the check glyph. Attaching a document of a type that already has a row supersedes that row at once (Replaced). A replacement after approval follows the same rule: Added until Send for review (submitRiderDocuments, Needs API for an ACTIVE or SUSPENDED rider), then Sent, then In review. Attaching alone never puts a document in review.
