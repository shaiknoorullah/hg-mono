Component gap: Focus order
On entering any screenOn a route change, focus moves to the screen's h1 (or, on a form step, its first field), never to Back. Exceptions: Code → the 6-digit field; Fix — edit plate → Licence plate; Fix — edit details → the field named in the reviewer's note; Capture → Take photo; Paused and Review → h1; an open Modal → its title. The orders below start from that landing point; Back is reached with Shift+Tab
Sign inWordmark (not focusable) → Mobile number → Send code → Call support. Call support is always last in the footer (consistent help, WCAG 3.2.6)
CodeBack → 6-digit code (focus on open) → Send the code again → Verify (off until 6 digits; the 6th digit or autofill submits) → Use a different number → Call support
DetailsBack → First name → Last name → Date of birth: Day → Month → Year → Email → Time zone → Continue → Call support. On a failed Continue, focus moves to the error summary; each item links to its field
VehicleBack → the radio group (one tab stop; arrows move between types) → Licence plate → Make → Model → Year → Colour → Continue → Call support. Switching to Bicycle or On foot removes the fields; focus stays on the radio
DocumentsBack → each row top to bottom (an added row is a link; a row not added: its Add button; a failed row: its action) → the footer primary → Call support. Row failures are announced once by the polite status line
FixBack → the document card: its remedy (primary) → the other remedy (tertiary) → Call support. After a fix, Send for review again appears as the footer primary, before Call support
Fix — edit plateFocus starts on Licence plate when the screen opens from Check your plate → Save plate
PayoutsContinue to Stripe → For support (a Disclosure: Enter or Space toggles, aria-expanded on the summary) → Call support. Stripe keys are read as text, in order
AccountEach row top to bottom (one link each) → Call support → Sign out → bottom bar (Home, Earnings, Account; aria-current on Account)
Every ModalInitial focus on the least destructive action (Cancel, Keep my scooter, Stay signed in); focus is trapped; closing returns focus to the control that opened it
