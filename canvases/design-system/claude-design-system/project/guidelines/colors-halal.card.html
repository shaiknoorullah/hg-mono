The green monopoly: the seal is the only filled solid green in the system. A halal state is a set, not a colour: fill, brass ring, shield and label always travel together. No red, ever: red would read as a religious ruling the platform does not make. Expired is cool slate with an outline shield and no brass ring, so it reads as “we can't currently vouch”, not as disabled chrome and not as a verdict on the food.

Only the halal badge, the certification panel, the admin checklist and the registered rider map-pin exception may use these colours.
