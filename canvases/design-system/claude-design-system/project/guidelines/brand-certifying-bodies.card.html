The client has permission to use the three logos; the files, and any usage rules each body gave with its permission, are coming in GitHub issue #116. Until they arrive, set the names in type as above; never draw, trace or approximate a logo. When they arrive: use each file as supplied (no recolouring, no redrawing), give the three the same visual size and weight, and follow each body's own rules where they differ from these. The order carries no rank, and the platform never compares one body's standard with another's.
