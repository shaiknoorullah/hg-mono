# Customer app — every screen

Phone sign-in to tracking, with loading, empty and error states

The HalalGoes customer app kit: each screen of `apps/customer` as an artboard, with variants
for server states (restaurant availability, checkout payment states, all order states) and the
baseline Loading / Empty / Error states. Amounts come only from API fields; halal badges only
from `halal.display_state`. Dashed outlines ("Show component gaps") mark placeholders for
components the system does not have yet. See `ui_kits/customer-app/README.md` for the file list.
