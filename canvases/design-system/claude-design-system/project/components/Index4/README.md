# Restaurant web — partner console

Sign-in, onboarding, the live order queue, menu review, hours, payouts, staff and settings, every screen with its loading, empty and error states.

The HalalGoes restaurant-partner kit (desktop, 1280+). Pick an artboard with the Screen, Variant and state controls above the frame; "Show component gaps" outlines every placeholder that stands in for a component the system does not have yet (#109). Screens mirror `apps/restaurant/src/routes`; every field shown exists in `contracts/openapi.yaml`, and every amount is server-priced. See `ui_kits/restaurant-web/README.md` for the file list.
