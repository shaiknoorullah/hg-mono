# Rider app — HalalGoes

Dark scheme, one offer at a time (30 s), a trip step for every AssignmentState, earnings and payouts

The HalalGoes rider kit, rendered live from the JSX files in this folder (compiled into `preview.html`).
It has 9 screens: sign-in, onboarding, home/availability, offer, active trip, earnings, payout
detail, delivery history and profile. Each has its contract variants and its loading, empty and
error states. The full screen list and rules are in `ui_kits/rider-app/README.md`.
