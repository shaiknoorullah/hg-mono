Owner decision (1 October): after an unpaid order is cancelled, expires or fails payment, "Put these items back in your cart" re-adds each line with the existing cart operations (addCartLine: same item, variant, add-ons, quantity and note) and opens the cart, where the server prices them again. A line that can't be added shows its own cart state (sold out, removed from the menu, restaurant closed). No contract change. Result: the cart itself, Cart — default, priced from a fresh quote. No separate confirmation screen. If a line could not be added, the cart opens with that line's state (Cart — item out of stock, chosen size sold out, removed from menu). The next three frames: while it runs, if it fails, and if the cart already holds another restaurant.
