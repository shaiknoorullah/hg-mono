Sheet: focus enters, is trapped, and returns to the trigger
  1. Open: focus moves to the dialog, named by its title "Pay with".
  2. Tab: Close (the Sheet renders it in the header, right after the title).
  3. Tab: the ways-to-pay radio group (one stop; arrows choose).
  4. Tab: "Pay with Visa •••• 4242" in the sticky footer.
  5. Tab: wraps to Close; focus never leaves the sheet.
  6. Escape or Close: focus returns to the "Change" row on Checkout that opened it.
Code: the CTA is passed through the Sheet footer prop (sticky footer), not as a child. Order matches the DS Sheet DOM: title → Close → children → footer.
DS components here use the canvas demo class because the DS has no forced-focus prop (Component gap: forced focus demo state). The brand, halal and slate samples use a demo class that mirrors the DS .hg-focus rule, so each flip (hg-on-brand, hg-on-halal) draws exactly as shipped.
