What's needed now, and the halal status line: one source for the copy

blocking_reason is a machine code (the spec’s own example: no_live_menu_item), never shown as-is. Each screen maps it to one sentence from the first table. Codes other than no_live_menu_item are proposed names for the server to confirm.
