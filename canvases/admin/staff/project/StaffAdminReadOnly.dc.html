Support agent

Reads queues and orders with personal details masked. Cancels an order only before the restaurant accepts. Refunds up to a set daily limit. No review decisions and no staff list.

Admin (your role)

Makes review decisions: documents, halal certificate checks, restaurant and rider applications. A menu item an admin adds for a restaurant is approved as it is created, and recorded in the audit log. Cancels an order at any stage; after the restaurant accepts, linking a support case is optional. Refunds up to a set daily limit. Sees names, roles and status in this list.

Super admin

Everything an admin can do, plus inviting staff, removing a leaver's access, resetting a colleague's two-step sign-in after confirming who they are, changing an issuing body's status, and revoking a certificate. The platform must keep at least two active super admins.
