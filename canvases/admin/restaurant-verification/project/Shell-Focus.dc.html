Grid cell in focus (LyteNyte default: focus on the active gridcell), and the grid keyboard map

LyteNyte grids: role grid, header and body rowgroups, aria-rowcount = data rows + 1, roving tabindex on gridcells
TabMoves into the grid once, onto the active cell. The grid is one Tab stop.
Arrow keysMove the active cell between cells and rows. The ring is on the cell.
Home, EndFirst or last cell in the row.
Ctrl+Home, Ctrl+EndFirst or last cell in the grid.
EnterOpens the row (applications, menu versions, certificates) or reviews the document (documents grid).
SpaceSelects the row where rows are selectable (documents, menu versions); those rows carry aria-selected.
EscapeLeaves cell editing; never closes the page.
