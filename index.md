# W6 Data: visual check

Side-by-side screenshots for the W6 Data work package (DataTable on LyteNyte, its cells,
FilterBar, FilterChip, ListPaneRow and EventLog) at 1440px. Made with
`pnpm --filter @hg/ui-web preview:shoot` against the live design system's project directory.

- `DataTable-full.png`: the live design system's DataTable preview on the left, ours on the right.
- Every other image is candidate-only: the live design system has no preview page for the cells
  or for the proposed composites.
