# Rider app: device-lab missions

Each mission here is a `<id>.yaml` for the redesigned rider app, run on the `hg_rider` emulator
as `com.halalgoes.rider.dev`, with flows from the folder above. Copy `example-rider-launch.yaml`
to begin. The format, the check and where results go are in
[tools/e2e/native/README.md](../../../README.md#missions).
