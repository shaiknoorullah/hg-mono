# Device-lab media

Files a mission may push to the emulator's photo library with `camera-media:` (to
`/sdcard/Pictures/<name>`, then media-scanned). Only `.jpg`, `.jpeg`, `.png` and `.pdf` files
directly in this folder are accepted. Keep them small, made up and free of personal data.

| File | What |
|---|---|
| `pod-sample-door.png` | A plain drawn door, 320×240: a stand-in proof-of-delivery photo |
